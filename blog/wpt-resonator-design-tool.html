WPT Resonant Filter Design Tool

April 20, 2026 2 min read
  • WPT
  • power electronics
  • tools

TLDR: A Streamlit app that designs and compares compensation network topologies for inductive wireless power transfer systems — source on GitHub.

Why I built it

Picking a compensation topology for a WPT link usually means grinding through the same AC circuit math for each candidate — SS, SP, LCC-S, and so on — then juggling spreadsheets to compare results. I wanted a single tool where I could set coil parameters once and immediately see how each topology performs, including realistic copper losses and component stress.

What it does

  • Supports six topologies: SS, SP, PS, PP, LCC-S, LCC-P.
  • Manual mode: enter component values and get frequency-sweep plots of gain, efficiency, impedance, coil currents, and capacitor voltage stress.
  • Auto mode: coarse log-grid search followed by local optimization to find the best-performing topology given your constraints.
  • RMS current limits and capacitor voltage rating checks enforced throughout.
  • Copper losses and FHA rectifier approximation included in every calculation.

Try it

Clone the repo and run streamlit run app.py. Everything runs locally in a browser — no server needed. GitHub →
